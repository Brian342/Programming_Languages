# Notes Java Project

Small Java project containing sample `Notes` utilities and a `Main` runner.

**Prerequisites:**
- Java 11+ (JDK)
- Maven 3.x

**Build**

Compile and package with Maven:

```bash
mvn clean package
```

Or just compile:

```bash
mvn compile
```

**Run**

Run the main class after compiling:

```bash
java -cp target/classes notes.Main
```

You can also run via the Maven Exec plugin (if available):

```bash
mvn exec:java -Dexec.mainClass="notes.Main"
```

**Clone & Quick Run (examples)**

Clone the repository (replace <repo-url> with your repo):

```bash
git clone https://gitea.kood.tech/briankimanzi/notes.git
cd notes
```

Quick method (compile the single source file and run):

```bash
# go to the Java source root that contains the `notes` package
cd src/main/java
# compile the Notes class
javac notes/Notes.java
# run the tool (replace `my_list` with the collection name you want to manage)
java -cp . notes.Notes my_list
```

Alternatively, use Maven to compile then run the class from `target/classes`:

```bash
mvn compile
java -cp target/classes notes.Notes my_list
```

Notes:
- The class is in the `notes` package, so use the fully-qualified name `notes.Notes` when running.
- `my_list` becomes the collection file name (e.g., `packing_list` → creates/uses `packing_list.txt`).
