# Company Reviews

This Dataset is a structured collection of reviews from different Giant companies in kenya over a period of time. 
It's commonly used for data mining, cleaning, EDA and machine learning.
The data was collected through web scrapping with tools like selenium, beautifulsoup and saved as csv file.
This data contains files for different companies i.e(Safaricom, IBM, Cisco, Kcb, co-operative, Microsoft, Google, Equity and Bolt) the columns in the dataset are 
1. Job Title
2. Job Rating
3. Time
4. Job Status
5. Cons
6. Pros
7. Company Name

## Features
- **Data Mining**: Utilizes python packages like Selenium and Beautifulsoup to collect the reviews dataset
- **Data Preprocessing**: Includes data cleaning(python=removing duplicates values, regex expressions and DateTime changing
- **Data Modelling**: Applying ML Algorithms on the dataset
